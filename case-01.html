Project Proposal - Connected Outdoor Urgent Care Rooms

CASE-01

Coursework · George Mason University (IT 343, IT Project Management) · Spring 2022

The problem

During COVID, a Northern Virginia hospital network wanted to see urgent care patients outdoors, but there was no Wi-Fi outside its offices, so staff couldn't update medical records. The outdoor rooms also needed good airflow and had to be able to handle emergencies.

The plan

Survey each center's size and network capabilities, then design an architecture that fits the existing network. Draw up schematics so the build and IT teams could repeat the setup efficiently, then order the components and build to a schedule. I budgeted the project at $800,000 over a 30-week timeline, with a schedule and cost plan in Microsoft Project.
